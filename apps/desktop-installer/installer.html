2. Restaurar una sede desde el VPS

Se descargara un dump de la sede elegida desde el VPS y se restaurara en la base local correspondiente.
Se rellena automaticamente con el nombre tecnico esperado para esa sede, pero puedes ajustarlo si necesitas otro nombre.
Debe apuntar a la sede exacta, por ejemplo http://68.183.105.135/tienda001.
Este no es un usuario de tienda como Caja ni uno operativo. Normalmente debe ser sistema.
Se usa solo para descargar el respaldo desde el VPS. En esta configuracion normalmente es 456789.
